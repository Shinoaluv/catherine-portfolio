# Design
Preserve the incumbent blush-pink / plum identity and existing portrait. Use readable sans-serif typography, a restrained rose accent, and light/dark themes. Organize content as resume sections with a narrow heading column and wider role list; use fine separators rather than cards for every activity. Keep full dates and publication status visible. Mobile uses a single column and a collapsible navigation menu. All links and controls have visible keyboard focus; respect reduced motion.

Activities use rounded, alternating blush and white cards with subject-specific icons per user request. Evidence buttons use descriptive View labels; empty URLs remain disabled without status copy.

Whole-site refinement: rounded white navigation, rose-filled primary actions, framed arched portrait, icon-marked section headings, paper-style research entries, featured nonprofit panel, blush service panel, award grid, softly framed photography, and rose contact panel. Preserve the admissions-first order and all resume claims. Mobile collapses grids into one column.
